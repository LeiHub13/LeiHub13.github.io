关于我

about.md

我是一名后端方向的开发者，主要使用 Java + Spring Boot 构建业务系统， 也使用 Vue 3 + TypeScript 完成前后端分离项目的前端部分。

从业务 CRUD 到高并发场景，我关注的不只是"能跑"，更是为什么这样设计： 缓存穿透怎么防、分布式锁怎么加、一人一单如何保证、RAG 检索链路如何落地—— 这些问题驱动我完成了下面的一系列项目。

毕业设计方向是 LLM + 教育：把大模型能力（答疑、出题、批改、学情分析） 以独立 Python AI 服务的形式接入 Java 业务骨架，做了一套完整的智能学习助手系统。
